# 一、两份文件分别是什么

| | Concept Note（概念说明） | MOU Draft（谅解备忘录草案） |
|---|---|---|
| **性质** | 写给 UNIDO 的合作建议书，用来“敲门” | 准备与 UNIDO 正式签署的框架协议 |
| **读者** | UNIDO SDG 创新与经济转型司（IET）下的公平生产、可持续标准与贸易处（PST）技术人员 | UNIDO 法务和管理层；学校签约审批部门 |
| **作用阶段** | 第一步：先让 PST 认可方向、指定对接人 | 第二步：技术对接认可后，再谈签约 |
| **约束力** | 无 | 大部分条款无约束力；知识产权、名称使用、保密、人员地位四条有约束力 |

## Concept Note 要表达的核心意思

1. **问题很具体**：植物纤维替代塑料的技术已经商业化，但缺少一套公认的方法来证明“替代了多少塑料、碳排放和材料代价是多少”。争议集中在三处：生物碳核算时点、替代边界设定、可回收/可降解声明适用哪套规则。
2. **后果**：一份完整的第三方碳足迹研究要数万欧元，发展中国家中小出口企业承担不起，实际上形成了贸易壁垒。这正是 PST（标准与贸易）的业务范围。
3. **华南理工能提供**：实验室、中试平台、检测平台和真实生产线数据，这些是咨询公司做不到的。
4. **三项交付物（18 个月）**：① 替代塑料核算方法 V0.1（方法规范 + 计算工作簿 + 报告模板）；② 技术—产业图谱（5 类技术、40 个以上条目、20 个以上经济体）；③ 一次南南技术对话（60–80 人）加两天培训模块。
5. **对 UNIDO 的要求很低**：不要钱、不新设机构，只请 PST 指定一名技术对接人（约 5–8 人日工作量），并就合作形式给出意见。
6. **主动交代利益冲突**：部分教师是相关企业的创始人或股东，因此提议由独立检测认证机构主持评审。

## MOU 要表达的核心意思

把 Concept Note 的合作内容写成框架协议：7 个合作领域、双方职责、联合指导委员会与秘书处、各自承担费用、知识产权与名称使用规则，期限 3 年。

# 二、发现的问题与已做的优化

两份文件整体质量较高，英文表达专业，没有大的结构问题。主要问题是**两份文件之间、中英文之间不一致**，以及**少数措辞超出学校目前能承诺的范围**。

**我没有改动、但建议核实的事实：**

- UNIDO 现行机构名称：IET 司、PST 处的英文全称。正式发出前请在 UNIDO 官网或向联系人核对。
- “山东大学‘清洁能源创新’大学联盟、ITPO 北京支持”这一先例：引用前请核实名称和事实。
- MOU 第九条称 UNIDO 名称和徽标受《专门机构特权与豁免公约》保护：建议沿用 UNIDO 法务提供的标准措辞。
- 实验室面积、设备值、A+ 学科等数据：请实验室核对是否为最新口径。

# 三、与此前“联盟”方案的关系（需要先统一口径）

此前的设想是成立“全球植物纤维替代创新联盟（GAPS）”或“国际植物纤维材料创新联盟（IPFIA）”，条件成熟时登记为国际性社会团体法人。这两份新文件的思路更稳妥：

- **先做事，后建组织**：以三项具体交付物开局，不以成立联盟开局。
- **网络不具法人资格**，现阶段不登记，名称中不使用 UNIDO。
- 联盟名称可以作为合作网络的名称，在 MOU 签署后由成员商定。

**建议**：与学校和 UNIDO 沟通时都使用新文件的口径，即“由华南理工大学主办、与 UNIDO 合作的国际学术—产业合作网络”。GAPS 或 IPFIA 作为备选名称，暂不对外使用。这样更容易通过学校外事审批和 UNIDO 法务审查。

# 四、去科研院、国际处谈话：要请求什么

**背景与时间点**：与联合国方面的 Teams 会议在 11 月 12、13 日。理想情况是在 **11 月 10 日前**拿到学校的原则同意和修改意见。

## 开场（2 分钟）

我们拟向 UNIDO 提交合作建议，请学校把关。文件目前仍是草稿，不会在学校同意前发出。合作对学校零风险、低成本：UNIDO 不出钱，学校不新设机构，不登记法人。

## 请科研院支持的事项

1. **原则同意**由实验室牵头推进这项国际合作，并认可它作为学校重点国际科技合作方向。
2. **第一阶段经费**：Concept Note 承诺“华南理工承担第一阶段直接费用”。需要确认经费来源（实验室自有经费、学校国际合作专项还是其他），以及大致额度。**请准备一份指示性预算带去。**
3. **秘书处人员**：文件承诺配备 2 名专职人员（其中 1 名全职）。需要确认用什么方式解决，例如博士后、科研助理或项目聘用。
4. **知识产权与成果开放**：方法学拟以 CC BY 4.0 开放许可发布，需要学校知识产权政策认可；同时请确认与企业签订数据共享和保密协议的合同模板与审批路径。
5. **利益冲突管理**：部分教师持有相关企业股权。请科研院确认学校的利益冲突申报和回避要求，使文件中的“独立评审”安排符合学校规定。
6. **核对实验室官方中英文名称**和对外宣传数据口径。
7. （可选）该项目成果能否纳入实验室考核或国际合作成果统计。

## 请国际处支持的事项

1. **签约审批流程**：学校与联合国专门机构签署 MOU 需要走哪些校内程序（国际处审核、法务审核、校长办公会），是否需要报教育部、省教育厅或外办备案或审批，以及大概需要多长时间。
2. **签署主体与签署人**：确认以学校名义签署、由校长签署；确认中英文本以哪个为准。
3. **对外联络口径**：Concept Note 写明“来函请寄国际处”，需要国际处同意作为对外联络窗口，并提供联系人。
4. **11 月 12、13 日的 Teams 会议**：
   - 是否需要国际处派人参加或事先备案；
   - 外事口径：哪些可以讲、哪些不能承诺（例如校长出访、经费）；
   - 能否先发 Concept Note，还是只做口头介绍。
5. **渠道支持**：国际处是否有 UNIDO 相关联系渠道，例如 UNIDO 驻华代表处、ITPO 北京、我国常驻维也纳联合国代表团，能否协助引荐。
6. **校长赴维也纳**：如需安排，需提前纳入学校年度因公出访计划。请国际处说明时间节点。
7. **南南技术对话**：如在国内举办，属于举办国际会议，需要提前了解审批要求和周期。
8. **名称使用**：确认“国际学术—产业合作网络”的对外表述，以及现阶段不使用“联盟”或 UNIDO 字样，是否符合学校外事管理要求。
